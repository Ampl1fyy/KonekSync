═══════════════════════════════════════════════════════════════════════════════
  QUICK REFERENCE — IF SOMETHING GOES WRONG
═══════════════════════════════════════════════════════════════════════════════

Shifts not showing on feed?
  → Make sure location permission is granted and you're "near" Makati.
  → Or manually set mock location to 14.5565, 121.0244 (Ayala Center) in dev tools.

AI matching button shows error?
  → Check that ANTHROPIC_API_KEY is set in Supabase Edge Function secrets.
  → Fallback: show sector filters instead and explain ranking is API-dependent.

Admin panel blank after login?
  → Check that admin@koneksync.ph has role = 'admin' in profiles table.

Chat messages not loading?
  → Supabase Realtime must be enabled for the messages table in the dashboard.

Expo Go can't connect?
  → Make sure phone and laptop are on the same Wi-Fi network.
  → Run `yarn expo start --tunnel` as fallback.
